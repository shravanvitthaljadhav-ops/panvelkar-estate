# Panvelkar Estate Stanford – Society Website Prototype

This is a free static website prototype for Panvelkar Estate Stanford Co-operative Housing Society, Badlapur.

## Included
- Home page
- Notices
- Wing/unit structure
- Owner/tenant/vehicle data-capture form
- Shop directory ASH01–ASH14
- 12 demo committee members
- Responsive mobile layout

## Important
The supplied unit structure calculates to:
- R1A: 13 × 9 = 117
- R1B: 7 × 2 = 14
- R2: 12 × 8 = 96
- R3: 12 × 8 = 96
- R4: 12 × 8 = 96
Total = 419

Please verify the official count before connecting a live database. The website currently generates 419 residential units from the floor patterns above (117 + 14 + 96 + 96 + 96 = 419), not 414.

The prototype form stores submitted data only in the visitor's browser localStorage. Do NOT use it to collect real resident personal data until a secure backend/database, authentication, access control, backups and privacy policy are added.
